プライバシーポリシー

最終更新日: 2026-10-30

このポリシーは、このサイト（apps.dangkang.com）と、このサイトからの直販版のご購入で、徳久 悟（屋号：interdisciplinary design lab）がお預かりする情報の扱いを定めるものです。各アプリの中での情報の扱いは、それぞれのアプリのプライバシーポリシーに記載しています。

1. このサイトの閲覧

このサイトは Cookie を使わず、アクセス解析のツールも置いていません。サイトは GitHub Pages で配信しているため、GitHub がセキュリティの目的で閲覧者の IP アドレスなどを記録する場合があります。その扱いは GitHub のプライバシーに関する声明に従います。

2. 直販版のご購入でお預かりする情報

決済は Link（Stripe の決済サービス）が処理します。ご購入の際、Link から次の情報を受け取ります。

  • お名前とメールアドレス
  • 国・地域、購入した商品、金額、日時

カード番号などの支払いに関する情報は Link が扱い、こちらには届きません。決済での情報の扱いは、Link のプライバシーポリシーに従います。

3. 利用の目的

  • アプリのお届けと、ご購入に関するご連絡
  • お問い合わせ・返金への対応
  • 法令で求められる取引記録の保存

4. 第三者への提供

法令に基づく場合を除き、お預かりした情報を第三者に提供することはありません。

5. 保存期間

取引の記録は、税法などの法令で定められた期間保存し、その後に削除します。

6. 開示・訂正・削除のご請求

ご自身の情報の開示・訂正・削除をご希望の場合は、下記までご連絡ください。法令で保存が求められる記録を除き、対応します。

7. ポリシーの変更

このポリシーは変更される場合があります。変更後のポリシーは、このページに掲載した時点から効力を発します。
